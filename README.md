## 三网直连实测能跑到多少：电信联通接近满速，移动上行是短板

电信和联通方向基本能跑满本地带宽，移动方向的上行被明显限制，这是能查到的公开实测里最一致的一条。2025 年 12 月一份公开发布的 HKG.Turin.Mini 测评记录把测试条件写得很清楚：深圳电信 500Mbps 本地线路，单线程上下行 475–478Mbps；济南联通 500Mbps 本地，545–572Mbps。到移动这里画风就变了——广东移动 1Gbps 线路上行只有 25–66Mbps，还伴随大量重传；武汉移动 33–37Mbps，宁波移动 37–41Mbps。下行倒是正常，宁波移动下行跑到 653Mbps，另一条 1Gbps 移动线路下行 933Mbps。

同一台机器上的国际和回国测速数据也能对上：Speedtest.net 上传 1988.96Mbps、下载 1879.80Mbps，联通上海 5G 上下行各约 350Mbps、延迟 64.10ms。

晚高峰数据受测试条件影响很大。上面那份 Turin.Mini 测评受限于 500Mbps 本地出口，另一份转述 DigVPS 的 Pulse 系列晚高峰单线程数据是电信 995Mbps、联通 975Mbps、移动 788Mbps。差别主要来自本地带宽上限和测试时段，不要把任何一个数字当成保底承诺。

结论：以下行为主的业务，移动用户的体验会打折。直播推流、大文件上传、需要稳定上行回源的场景，先想清楚这一点。纯下载、看视频、普通建站这类下行主导的用法，三网都能接受。

## 买之前容易踩的几个坑

优惠码的位置、流量计费的算法和价格的历史变动，这三件事在官网首页都看不出来，但都会实际影响你花多少钱。

优惠码填在购物车页，不在选套餐那一步。官方购买流程是：选节点和产品线 → 点 Order Now → 在 Configure 页选计费周期 → Continue 加入购物车 → 在 Review & Checkout 页面填写 Promo Code → Checkout。不少人卡在选套餐页面找输入框，那里没有。官网目前也没有公示任何长期有效的码，结账时可以试试手头的码是否有效，别抱着一定有折扣的预期做预算。

流量这块，官方 FAQ 明确只对出站流量计费，入站完全免费，所以规划用量时按上行算就行。配额在每个计费周期开始时重置，超限之后是限速，不是停机，具体限到什么程度取决于套餐，官方没给数值；第三方有“限速到 20 kb/s”的说法，只能当参考。另外官方提供了单独购买流量包的工具，不必为了加流量去升级整个套餐。

剩下的三条值得单独列出来：

- **老测评里的价格别照搬。** 2025 年 8 月的测评里，香港 Pulse Mini 还是 $39、40GB 磁盘；现在是 $59、60GB。香港 Turin 的 Air 和 Pro 在 2025 年底的记录里是 $99 / $199，现在第三方价目是 $129 / $299。香港带宽成本会波动，判断时以当前结算页为准。
- **首页价格不能直接对照香港套餐。** 官网首页展示了两组不同 CPU 的六档价格，但没有标明节点和产品线，跟香港 Pulse 的公开价目对不上。要看具体价格，进对应产品线商店页看，或者进结算页看总额。
- **IPv6 和备份别默认有。** 2025 年 12 月那台 Turin.Mini 的实测记录里，IPv4 在线、IPv6 显示 Offline，官方页面也没有承诺双栈。每日自动备份到 AWS S3 这个说法只见于第三方测评，官方商店页在本文核对时没有写明，当加分项而不是采购依据。

## 谁适合买，谁可以看别家

面向中国大陆用户建站和跨境业务适合；预算每月只有个位数美元、或者以移动上行上传为主的场景，把钱花在别处更划算。

适合的情况比较具体：外贸独立站和跨境电商，客户主要在东亚；需要免备案、又受不了晚高峰抖动的企业官网和 API 服务；游戏服务器和加速类应用，看重香港的低延迟；以及需要 1–5Gbps 端口但不想自己拉专线的业务。

不适合的情况同样具体。预算敏感的个人用户，同样的钱在别家能买到配置更高但线路普通的机器，日常挂个脚本、搭个小站其实够用。以移动网络上传为主的直播和数据回传业务，香港和日本节点在移动上行上都有限制，新加坡节点的移动表现反而更好。需要 IPv6 双栈、或者需要厂商书面承诺备份策略的合规场景，也要提前问清楚。

还有一条跟建站直接相关：GoMami 官网宣传的最高 600Gbps DDoS 清洗能力，在官方 FAQ 里的准确说法是——所有实例默认带 best-effort 防护，自动检测清洗、无需人工介入，正常流量不受影响；某个 IP 的攻击影响到其他客户时会被黑洞 30–60 分钟，自动释放，无法人工干预；600Gbps 高级清洗属于付费加购项。部分第三方文章把它写成“全系免费包含 600Gbps”，跟官方文档的口径不一致，做预算时按官方说法来。

同时有第三方测评提到，这套防护策略偏激进，做反向代理时可能感受到上行带宽被限制。如果你打算拿香港节点当回源中转或反代入口，这一点比 DDoS 数字本身更值得关注。
